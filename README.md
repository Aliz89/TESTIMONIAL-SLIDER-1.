# TESTIMONIAL-SLIDER-1.
TESTIMONIAL SLIDER 1. Used HTML, CSS and Javascript. 

Vertical Testimonial Slider

A simple vertical testimonial slider built with HTML, CSS, and JavaScript.
This project allows users to navigate between testimonials using up and down arrow buttons.

🎯 Project Purpose

This is a small weekday learning project focused on improving my JavaScript DOM manipulation skills and understanding how position-based animations work.

Even small projects like this help reinforce important concepts and build practical experience.

⚙️ Features

Vertical sliding animation

Up and down arrow navigation

Smooth position-based movement using JavaScript

Clean and simple UI

Beginner-friendly code structure

▶️ How It Works

The slider moves by changing the top position of the slide container.

Example logic:

Clicking the down arrow
→ decreases the top value
→ slide moves up
→ next testimonial becomes visible

Clicking the up arrow
→ increases the top value
→ slide moves down
→ previous testimonial becomes visible
